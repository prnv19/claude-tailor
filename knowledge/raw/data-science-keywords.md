## TL;DR and FAQ

- The most important data scientist keywords are Machine Learning, Python, TensorFlow, PyTorch, Deep Learning, SQL, NLP, MLOps. "Include 25-35 keywords matching the job description."
- FAQ: "Include 25-35 highly relevant keywords that match the job description. Focus on ML frameworks, programming languages, and methodologies you've actually used in production." MLOps and deployment terms "appear in most modern data scientist job descriptions."

## Keyword groups (term lists)

- **ML frameworks**: TensorFlow (Keras, TF Lite, TF Serving, TensorBoard, TFX), PyTorch (Lightning, Torchvision, Torchaudio, ONNX), Scikit-learn, XGBoost (LightGBM, CatBoost, ensembles), Spark MLlib.
- **Languages and tools**: Python, R, SQL, Scala, Java, C++, Julia. Pandas, NumPy, Polars. Matplotlib, Seaborn, Plotly, Bokeh, D3.js. Jupyter, Colab, VS Code, PyCharm. Statistical analysis, hypothesis testing, A/B testing, statistical modeling.
- **Methods**: supervised (classification, regression, decision trees, random forest, SVM), unsupervised (clustering, K-Means, DBSCAN, PCA), deep learning (CNN, RNN, LSTM, GRU, Transformers), NLP (sentiment analysis, NER, BERT, GPT), computer vision (classification, detection, segmentation, OpenCV, YOLO), reinforcement learning (Q-learning, DQN, policy gradients).
- **Data science and analytics**: EDA, feature engineering and selection, big data (Spark, Hadoop, Hive, HBase), time series (ARIMA, Prophet), recommendation systems (collaborative filtering, matrix factorization), anomaly detection (isolation forest, fraud detection).
- **MLOps and deployment**: model deployment and serving, versioning, REST APIs, Flask, FastAPI, Docker, Kubernetes, CI/CD for ML, model monitoring and drift, model registry, MLflow, Weights & Biases.
- **Cloud**: AWS (SageMaker, Lambda, Glue, S3, EC2, EMR, Bedrock), Azure ML and Databricks, GCP (Vertex AI, BigQuery ML), Databricks (Delta Lake), Snowflake (Snowpark).
- **Databases and pipelines**: PostgreSQL, MySQL, SQL Server, MongoDB, Cassandra, Redis, DynamoDB, BigQuery, Redshift, data lakes, ETL/ELT, Airflow, Prefect.
- **Evaluation**: cross-validation, hyperparameter tuning, grid and random search, accuracy, precision, recall, F1, ROC-AUC, RMSE, MAE, R², confusion matrix, AutoML.

## Strong example (paraphrased)

- Experience bullets pair a general term with specific tools and a result, e.g. "machine learning models" built with Python, TensorFlow, and PyTorch, "improving prediction accuracy by 25% and reducing false positives by 40%." Others cover CNN image classification, BERT sentiment analysis over 1M+ reviews, MLOps pipelines cutting deployment "from weeks to hours," and forecasting with ARIMA and Prophet.
- Skills in eight categories: ML Frameworks, Programming, Data Science Tools, ML Methodologies, MLOps & Deployment, Cloud Platforms, Databases, Statistics.

## Weak example

- A "Data Analyst" with bullets like "Worked with data to build predictive models," "Used Python for analysis and visualization," "Helped improve business decisions," and Skills "Python, Data Analysis, Statistics, Excel." Fails for: no frameworks, no methods, no deployment terms, vague descriptions, no quantified results.

## Integration strategy

1. **Match the JD**: required frameworks, languages, methods, deployment requirements.
2. **Use keywords naturally**: "Don't keyword stuff." Place them in the summary (e.g. "Data Scientist with expertise in Machine Learning, Deep Learning, and MLOps using Python, TensorFlow, and PyTorch"), experience bullets with context and results, a categorized Skills section, and projects.
3. **General and specific terms together** (Machine Learning + TensorFlow).
4. **Show impact with keywords**: not "Built ML models to improve predictions" but models named with tools and measured results.
5. **Modern practices**: MLOps, current frameworks, cloud ML services.
