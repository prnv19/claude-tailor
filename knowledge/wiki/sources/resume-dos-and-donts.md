# Resume Do's and Don'ts

> **Raw source**: `../../raw/resume-dos-and-donts.md` (research notes)
> **Author / origin**: Harvard Mignone Center for Career Success (Harvard Extension School resources page + sample resumes).
> **Date published / accessed**: Page live 2026, samples PDF dated 2025-08; accessed 2026-10-01.
> **URL**: https://careerservices.fas.harvard.edu/resources/hes-create-impactful-resumes-and-cover-letters/

## Key highlights
1. **Tailor to each position.** A university career office states it as the first DO.
2. **Reverse chronological order**, most recent first, inside every section.
3. **Phrases, not sentences**: begin each line with an action verb, no personal pronouns, quantify where possible.
4. **Language test**: specific not general, active not passive, clear and direct not embellished, easy to scan, fact-based.
5. **Never include a photo, age, gender, or references**, and never start lines with dates.
6. **Section order flexes with relevance**: Education can move to the end, Skills can move up for programming roles, relevant project sections can move above Experience.

## Unique contributions
- An **institutional, non-vendor** source. It corroborates the wiki's core rules without selling anything.
- Explicit **"don't start lines with dates"** rule, which the template already satisfies with right-aligned dates.
- Explicit **"no abbreviations unless industry-standard"**, which pairs with the spell-out rule in `ats-friendly-resume-guide.md`.

## Key claims
- DOs: tailor, white space, reverse chronological, check the PDF conversion, know the material.
- DON'Ts: pronouns, non-standard abbreviations, narrative style or slang, photo/age/gender, references, lines that start with dates.
